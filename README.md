# Traffic Anomaly Detection using Low-Rank Matrix Decomposition

## Project Overview

This project focuses on detecting traffic anomalies using Low-Rank Matrix Decomposition techniques. The project analyzes urban traffic speed data to identify unusual traffic patterns and reconstruct missing traffic information.

The implementation is developed in Python using Jupyter Notebook.

---

## Features

- Data preprocessing
- Traffic speed data analysis
- Matrix representation of traffic data
- Low-Rank Matrix Approximation
- Singular Value Decomposition (SVD)
- Traffic anomaly detection
- Data visualization
- Performance evaluation

---

## Dataset

Dataset Used:
Guangzhou Urban Traffic Speed Dataset

## Installation

Clone the repository

```bash
git clone https://github.com/neeta-05/traffic-anomaly-detection.git
```

Move into the project folder

```bash
cd traffic-anomaly-detection
```

Install the required libraries

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

Launch Jupyter Notebook

```bash
jupyter notebook
```

Open

```
Traffic_Anomaly_Detection.ipynb
```
